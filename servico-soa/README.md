# Serviço Rede de Apoio (Java / Spring Boot)

Backend da disciplina de SOA e Web Services.

Quando um cidadão faz o check-in "preciso de ajuda" no app, alguém precisa agir. Este serviço cadastra agentes comunitários de saúde e voluntários por bairro, recebe os pedidos de ajuda, encaminha cada um para um agente disponível e acompanha o atendimento até a conclusão.

Ele conversa com a API principal em C# por REST para validar o cidadão.

**Em construção.** Plano: Spring Boot, JPA, migrações com Flyway, documentação com Swagger, testes com JUnit e login dos agentes com Spring Security e JWT.
